NO-API VERSION — ENGLISH UI

- index.html is a static app. It needs no API key and no backend.
- The UI is English; generated eBay.it listing text is Italian.
- The image search button opens Google Images and Bing Images in new tabs using the entered brand/product/size.
- Since browser security (CORS) and search-engine restrictions prevent reliable direct importing of search results, select and save an image manually, then add it from iPhone. You can also add a direct image URL.
- The app does not scrape Amazon reliably and does not publish to eBay.
- Verify product facts and only reuse photos you have permission to use.
