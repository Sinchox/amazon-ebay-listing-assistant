How to use photo search

  1. Tap “Search Google + Bing Images”. Both searches open in new tabs.
  2. Check the exact brand, product name and size before using an image.
  3. Save a permitted image to Photos, then use “Choose photos from iPhone” to preview it here.
  4. Alternatively, add a direct image URL. Some image hosts block previews.
